# tax-prisa – מחשבון פריסת מס

ייחוס הפרשי שכר, פיצויים (החלק החייב) או הכנסה חד-פעמית לשנים קודמות, וחישוב שיעור מס לניכוי במקור.

- מדרגות מס ושווי נקודת זיכוי לשנים 2020–2026 (כולל הרחבת מדרגות 2026, תיקון 288).
- חישוב נקודות זיכוי לכל שנה מפרטי הנישום, עם אפשרות לתיקון ידני.
- זיכויים נוספים בשקלים לכל שנה (פנסיה, ביטוח, תרומות, ישוב מזכה).
- הפקת PDF עם נתוני החישוב בלבד. הפרטים האישיים ממולאים ידנית.

הכול רץ בדפדפן. שום נתון לא נשלח לשרת.

## קבצים
- `index.html` – האתר.
- `engine.js` – מנוע החישוב (מדרגות, נקודות זיכוי, פריסה).
- `engine.test.js` – בדיקות: `node --test engine.test.js`.
- `lib/` – html2canvas 1.4.1 ו-jsPDF 2.5.1 (רישיון MIT) להפקת ה-PDF.
